- [ ] 1. Say: `Write a file called 'order_utils.py' — a small order/billing helper module, at least 100 lines long. Give it a module docstring, two module-level constants (TAX_RATE = 0.08 and CURRENCY = "USD"), and these functions, each with its own docstring and a small body: 'calc_tot(items)' sums each item's price * qty; 'fmt_money(n)' returns a "$0.00"-style string; 'chk_stock(item, qty)' returns whether qty <= item["stock"]; 'mk_order(items)' builds and returns an order dict; 'apply_disc(total, pct)' returns the discounted total; 'tax(total)' returns total * TAX_RATE; 'parse_line(line)' parses "name,price,qty" into a dict; and 'summarize(order)' returns a multi-line text summary that calls 'calc_tot', 'fmt_money', and 'tax'. The script must modify only 'order_utils.py'. Important: perform the rename by writing and running that script — do NOT use your Edit/Write tools to change 'order_utils.py' directly.`
